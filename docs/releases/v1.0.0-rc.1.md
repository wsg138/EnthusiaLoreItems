# EnthusiaLoreItems 1.0.0-rc.1

This is the automated release candidate produced by WP-04. It is **not production-approved** until the WP-05 live Paper/Leaf acceptance matrix is completed.

## Included scope

- durable lore-item definitions, adoption, delivery, tracking, template revision/update, destructive administration, and mass distributions;
- bounded database and Paper-side work queues with explicit defer/reject/review behavior;
- schema migrations through V7 with upgrade and interrupted-migration recovery coverage;
- stable Bukkit service API `net.enthusia.loreitems.api.v1.LoreItemsServiceV1` for later EnthusiaTags integration;
- operator backup, restore, rollback, degraded/read-only, queue/review, marker-repair, and incident procedures;
- deterministic WP-04 profile evidence and reproducible shaded-jar verification.

## Release assets

The prerelease workflow publishes the shaded `EnthusiaLoreItems.jar`, SHA-256 checksum, CycloneDX JSON SBOM, Gradle dependency manifest, normalized jar-entry manifest, automated profile result, and test-report archive from the exact tagged merge commit.

## Acceptance boundary

Do not treat this RC as a production release. WP-05 must execute the committed live acceptance matrix against the intended Paper/Leaf environment and may remediate only confirmed defects before `v1.0.0`.
